# Repository metadata

## Short description

Configurable NDT Digital CLI for generating large-scale XML sitemaps, sitemap indexes, and robots.txt files for programmatic SEO.

## Detailed description

NDT SEO Indexer is a Node.js and TypeScript CLI for generating `sitemap.xml`, sitemap indexes, `robots.txt`, and batched sitemap files from static, PostgreSQL, CSV, or JSON sources.

It was created for programmatic SEO scenarios where systems need to expose many public indexable pages without mixing sitemap generation responsibilities into the main product API.
