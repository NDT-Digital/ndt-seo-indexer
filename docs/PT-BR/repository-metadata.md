# Metadados do repositório

## Descrição curta

CLI configurável da NDT Digital para gerar sitemaps XML em escala, sitemap indexes e robots.txt para SEO programático.

## Descrição detalhada

O NDT SEO Indexer é uma ferramenta CLI em Node.js e TypeScript para gerar arquivos `sitemap.xml`, sitemap indexes, `robots.txt` e sitemaps em lote a partir de fontes estáticas, PostgreSQL, CSV ou JSON.

O projeto foi criado para cenários de SEO programático, onde sistemas precisam expor muitas páginas públicas indexáveis sem misturar a responsabilidade de geração de sitemap com a API principal do produto.
